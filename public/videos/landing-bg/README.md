# Landing Page Background Video

Place your background video file here.

### Recommended Format:
- **File name**: `background-video.mp4` (or `bg-video.webm`)
- **Resolution**: 1080p (1920x1080) or 4K, 24-30fps
- **Encoding**: H.264 / AAC or WebM for web performance
- **File size**: Preferably compressed under 10MB-15MB for fast loading

### Public Path in App:
Once placed here, you can reference it as:
`/videos/landing-bg/background-video.mp4`

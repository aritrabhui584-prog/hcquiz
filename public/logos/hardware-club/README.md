# AEC Hardware Club Official Logo

Place your official club logo image files here.

### Recommended Formats:
- **Vector**: `club-logo.svg` (crisp at any scale)
- **Raster / Transparent PNG**: `club-logo.png` (high-res transparent background)
- **Modern Web**: `club-logo.webp`

### Public Path in App:
Once placed here, you can reference it anywhere in the application as:
`/logos/hardware-club/club-logo.svg` (or `.png` / `.webp`)
